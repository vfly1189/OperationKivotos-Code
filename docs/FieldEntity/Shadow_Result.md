## 측정 방식

실제로 스포너를 켜고 끄는 정책은 하나(이번엔 ⑦ CullingGroup)만 두고, 나머지 6개는 **그림자**로 같은 플레이어 위치를 받아 계산과 로그만 한다.

- 정책은 플레이어 위치와 **자기 직전 집합**만 본다. 몬스터 상태와 무관하므로 그림자도 실제 정책과 똑같이 계산된다.
  → 한 번의 플레이로 7개를 **같은 경로 위에서** 비교한다. 손 조작이어도 공정하다.
- 그림자마다 직전 집합 · 인스턴스(칸 캐시 · CullingGroup)를 따로 든다. 실제 정책의 집합을 넘기면 히스테리시스가 남의 상태로 판정한다.
- 매 프레임 동등성 검사: ⑤ = ⑥(같은 프레임), ⑦ = ⑤의 직전 프레임.
- 로그: `MetricsLogs/activation_{실제 정책}_shadow_{시각}.csv` — 7개가 한 파일에 같은 프레임 번호로, 머리 줄에 정책 설정 · 동등성 요약.
- **그림자로 잴 수 없는 것**: 프레임 시간 · 스파이크 시간 · 풀 사용량 · 화면 안 등장/소멸 · 끌고 온 몬스터 소실. 실제 몬스터가 있어야 생긴다 → 단독 측정(그림자 끔, Phase 3).

코드: `ActivationManager`(실제 1 + 그림자 Run 목록) · `ActivationPolicies`(①~⑦ 생성, 0-1 고정값 한 곳) · `ActivationLog` · GameScene 인스펙터 `Activation Policy` / `Activation Shadows` (`026bbfee`).

## 3. 예측과 다른 곳 — 전부 이유가 있다

| 항목 | 실측 / 예측 | 이유 |
|---|---|---|
| ⑤⑥⑦ 한 프레임 최대 변경 | 17 / 34 | **정의 차이.** 예측은 0.5m 걸음 단위, 실측은 프레임 단위(약 144 fps, 한 프레임 0.1m 안팎). 거리 방식은 스포너가 원을 하나씩 넘으므로 잘게 나누면 한 번에 1개(17마리)만 바뀐다. 칸 방식은 걸음을 아무리 잘게 나눠도 칸을 넘는 순간 칸 하나 분량이 한꺼번에 바뀐다(③ 68 · ④ 51 그대로) |
| ③ 원본 최대 변경 | 68 / 54 | **경로 차이.** x = −50 칸 경계를 넘는 순간 스포너 2개가 켜지고 2개가 꺼졌다(17 × 4). 예측 경로는 이 칸 열을 지나지 않았다. 변형 맵에서도 68 → 이 맵에서 ③의 최악값은 68 |
| ⑤⑥⑦ 원본 최대 활성 | 85 / 102 | **경로 차이.** 102는 스포너가 가장 몰린 한 지점의 값. 이번 경로가 그 지점을 지나지 않았다 |
| ①② 떨림 | 0 / 2% | **조작 차이.** 예측 2%는 섹터 경계 1m 왕복. 손 조작으로는 그 상황이 안 생겼다 |

→ **순간 비용 격차는 예측보다 실제가 크다: ③ 68 대 ⑤ 17 (4배).**
변형 맵 예측의 "흩어질수록 ⑤ 스파이크 34 → 17"은 프레임 단위에선 두 맵 모두 17이라 구분되지 않는다.
