## 1. 월별 로드맵

### 🗓️ 6월 — 스킬 시스템 기반 구축 (Foundation)
> 목표: 하드코딩된 캐릭터 스킬을 **데이터로 정의하는 파이프라인** 구축

- [ ] **`SkillDataSO` 스키마 설계** — 스킬 = 이벤트 타임라인 데이터 (발동시점별: VFX 생성 / 데미지 윈도우 / 카메라 / SFX / 히트스톱)
- [ ] **`SkillExecutor` 런타임** — SO를 읽어 시퀀스를 실행하는 공용 실행기, `BaseCharacter`에 통합
- [ ] **검증용 마이그레이션 (PoC)** — Serika·Hoshino 2명을 하드코딩 서브클래스 → 데이터 정의로 전환
- [ ] **플레이스홀더 수치 정식화** — 에너지 회복 하드코딩 제거 → `CharacterDataSO`/엑셀 기반 이전
- 📦 **산출물**: 데이터만 바꿔 스킬 1개가 동작하는 구조 + 전/후 비교(서사용)
- ⚠️ **착안점**: PoC에서 캐릭터별 예외 패턴을 미리 뽑아두면 8월 전체 마이그레이션 리스크가 줄어든다.

### 🗓️ 7월 — 게임 저즙 & 타격 이펙트 시스템 (Game Feel)
> 목표: 영상 체감을 끌어올리는 **재사용 피드백 레이어** (6월 시스템 위에 부품으로)

- [ ] **HitStop 매니저** — 타격 시 시간정지, 타임스케일 분리(UI/연출 영향 없게)
- [ ] **카메라 셰이크** — 임펄스 기반(Cinemachine 사용 시 연동), 강도 데이터화
- [ ] **타격 VFX 시스템** — 임팩트 이펙트를 **기존 PoolManager로 풀링** 생성
- [ ] **데미지 숫자 연출 고도화 + 넉백**
- [ ] **전 구간 적용** — 일반공격 + 스킬 + 보스 피격에 일괄 연결
- 📦 **산출물**: "타격감"이 확 살아난 전투 클립 (면접 1차 통과용)

### 🗓️ 8월 — 궁극기 컷씬 & 전체 캐릭터 마이그레이션 (Showpiece)
> 목표: 6·7월 시스템 위에서 **풀 연출 궁극기** 완성 + 전 캐릭터 데이터화

- [ ] **컷씬 시스템 고도화** — 전용 카메라 + 시간정지 + VFX를 Timeline+스킬시스템으로 통합 (보스 Timeline 코드 재활용)
- [ ] **나머지 캐릭터 마이그레이션** — 남은 캐릭터를 데이터 주도 스킬로 전환, 하드코딩 서브클래스 정리
- [ ] **E 스킬 정식화** — 현재 빈 껍데기인 E 스킬 로직 채우기
- 📦 **산출물**: 캐릭터별 차별화된 궁극기 연출 풀세트
- ⚠️ **리스크**: 마이그레이션 변동성이 가장 큼(캐릭터별 예외). 6월 PoC 결과에 의존.

### 🗓️ 9월 — 완결성 마감 & 쇼케이스 (Polish & Ship)
> 목표: "한 바퀴 완결되는 게임" + 포트폴리오 자료 갱신

- [ ] **세이브/로드 완결** — `WalletManager` 재화 로드, 파티/강화 상태 완전 복원

- [ ] **밸런스 패스** — 캐릭터/무기/몬스터/드롭 수치 1차 조정
- [ ] **쇼케이스** — 데모 영상 재촬영, README/DETAIL.md 갱신, 스킬 시스템 기술 블로그 글(Velog)

## 3. 면접 대비 — 이 작업으로 답할 수 있게 되는 질문들

스킬 시스템을 만들면 자연스럽게 다음 질문의 답이 생긴다.

- 데미지 판정 타이밍을 애니메이션과 어떻게 동기화했나? (→ 이벤트 윈도우 데이터화)
- 신규 스킬 추가 비용을 어떻게 줄였나? (→ 하드코딩 서브클래스 → 데이터 정의, 전/후 비교)
- 히트스톱 중에 다른 시스템의 시간은 어떻게 분리했나? (→ 타임스케일 채널 분리)
- VFX 생성 시 GC를 어떻게 막았나? (→ 기존 PoolManager 연동)
- 보스 연출 시스템과 캐릭터 스킬 연출을 어떻게 공통화했나? (→ Timeline 일반화)
