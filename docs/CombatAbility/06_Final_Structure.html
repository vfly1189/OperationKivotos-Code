ctx 규칙

  1. 매번 바뀌는 것만 담는다
    시전자 · 타겟 출처 · 소켓 · 이번 패턴 칠판 · 토큰. 고정 값(VFX · 반지름 · 개수)은 Event · Placement 필드에
  2. 타겟은 Transform이 아니라 "묻는 창구"
    패턴 시작과 신호 사이 몇 초 — 그 사이 캐릭터가 바뀌어도 Fire 순간의 타겟을 노린다
  3. memo는 BMC가 아니라 Runner가 넣는다
    패턴마다 하나를 재사용하고 시작할 때 비운다 — BMC는 memo를 모른다

5. Event — 상속은 한 번, 위치 · 간격은 조합

6. PointEmitter — 간격 · 묶음 · 취소

7. Placement — 기준점 4가지 × 모양 4가지

Placement 규칙

  1. Collect는 순수 — Fire 순간 한 번
    대기 · 부수효과 없음, 점 순서 = 실행 순서. 한 번 모으니 위치가 자연히 고정된다
  2. 점의 방향(PointFacing)은 Placement가
    Inherit · Outward · Inward — 기하라서. 프리팹 자체 자세 보정(_vfxEuler)만 Event에
  3. 기준점은 Pose(위치 + 방향)
    facing = AnchorForward · TowardTarget · World, offset은 그 방향 기준. 기울기는 버린다

8. 보스 프리팹 — 흐름과 반응 조각을 다른 가지에

10. 취소 경로 — 사망 · 회수 때 무엇이 멈추나

계약 8가지

  1. Event는 PatternEvent를 한 번만 상속
    위치 · 간격은 PointEmitter 필드로 조합
  2. 분기는 Task 조건
    고르기(Choose)와 분기(_ifKey)를 뗀다 — Event 안에 if가 없다
  3. Collect는 순수
    Fire 순간 한 번, 점 순서 = 실행 순서
  4. 아래층은 ctx만 읽는다
    BMC 이름이 Event · Placement 코드에 없다
  5. 대기 뒤에는 토큰부터
    풀에서 재사용된 시전자를 건드리지 않게 — PointEmitter가 대신 확인
  6. 같은 Task 안 순서 보장
    기다리지 않는 Event는 Fire 안에서 끝 → 앞 Event의 memo를 뒤 Event가 바로 읽음
  7. memo는 패턴 하나 동안만
    Runner가 재사용, 시작마다 비움
  8. 패턴은 원자 실행
    끊는 건 사망 · 회수뿐, 취소 시 PatternEnded 없음(= 정상 종료만)
