수동 짝맞추기의 함정
1. 팝업 세션의 영구 고정
팝업 한 세션 열람 = Global에 +287MB 영구 고정 — 닫아도·씬을 옮겨도 게임 종료까지 안 내려옴
2. 몬스터 HP바 누수 (실제 발견·수정)
DontDestroyOnLoad 캔버스에 방치돼 자가정리가 안 됨 → Memory Profiler GameObject +291
3. 구조적 원인
수명 관리가 개인의 주의력에 의존 → 실패가 반복 → "기억"이 아니라 구조로 정산할 필요
