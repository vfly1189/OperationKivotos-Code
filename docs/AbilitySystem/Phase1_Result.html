01AbilityRunner — admission / fire 분리 + 읽기 API

TryCast 한 덩이를 셋으로. 몹/보스 호출부는 TryCast(=Commit+Fire)라 무변경.

// 게이트+커밋: 통과 시 쿨만 시작(이펙트 X). 입력 시점 상태 전이 결정용
public bool Commit(AbilityData a, AbilityContext ctx);
// 비게이트: 캐스트타임 + 이펙트 + GrantsTags try/finally
public UniTask Fire(AbilityData a, AbilityContext ctx, CancellationToken token);
// 편의(몹/보스/E 즉발): Commit 성공 시 Fire
public UniTask TryCast(AbilityData a, AbilityContext ctx, CancellationToken token);
// 읽기 API — 쿨 상태 _cd:(end,dur) 저장 → CDR에도 채움비율 정확
public float CooldownRemaining(AbilityData a);
public float CooldownDuration(AbilityData a);

02쿨 값의 출처 = CharacterDataSO (러너는 모름)

쿨 "값"은 SO에 두고 캐스터가 ctx.CoolDown으로 건넨다. 러너는 결합되지 않는다.

// AbilityRunner.StartCooldown
float cd = ctx.CoolDown >= 0f ? ctx.CoolDown : a.Cooldown;   // 몹은 안 건넴 → a.Cooldown 폴백
_cd[a] = (_clock.Now + cd, cd);
  • BaseCharacter.SlotCooldown(slot) = 슬롯 → Stat.GetData().QSkillCoolTime/ESkillCoolTime 매핑.
  • 쿨 상태는 러너 인스턴스(캐스터별)가 소유 → 같은 E 에셋을 공유해도 캐릭터 간 쿨이 안 섞인다.

03BaseCharacter — 입력=Commit, 비트=Fire

쿨·궁게이지는 입력 시점 소비(컷신 내내 쿨이 도는 게 보임), 이펙트는 애니 비트가 발사.

UseSkillQ → 궁게이지 만충 검사 → Commit(쿨 입력 시점 시작) → ConsumeUltimateGauge → ChangeState(QSkillCutScene)
  ⋯ 컷신(OnSkillEnter/OnCutsceneEnded 무변경) → Q_Skill 애니 ⋯
  → [AbilityBeat] → UseAbility(Q_Skill,beat) → Fire(이펙트)
  • UseSkillE — Commit → ChangeState(E_Skill) → Fire(즉발). UseAbility 안 거침 → 쿨 시작 보장.
  • UseAbility — Fire 전용(비트 경로). 쿨/코스트 안 건드림.
  • 읽기 파사드 — SlotCooldownRemaining/Duration(slot), IsUltimateReady(에너지 만충 && Q 쿨 0).
  • 평타 — 쿨 없이 StateMachine으로 게이팅(Attack 재진입 차단 = 애니 길이가 발사 간격). CharacterCombat 소멸.

04UI — 러너 폴링으로 이관

쿨이 절대시각(무tick)이라 "쿨 끝남" 이벤트가 없어졌다 → 폴링.

UI소스방식
쿨 채움 링러너 CooldownRemaining/Duration (파사드 경유)매 프레임 폴링(GameSceneCanvas.Update)
궁 준비 글로우(활성)bc.IsUltimateReadyUpdateCooldowns 폴링에 얹음
궁 준비 글로우(벤치)bc.IsUltimateReadyPartySlotUI.Update() 폴링 → 절대시각 쿨 끝나는 순간 점등
에너지 바 · HPOnEnergyChanged · OnHpChanged이벤트 유지

미발동 스킬은 CooldownRemaining=0 → SkillIconUI가 currentCool>0일 때만 나눗셈 → 0 나눗셈 없음.

06검증 & 남은 것

에디터에서 필요 소스 레벨은 죽은 심볼 전수 grep 후 잔여 참조 0(단 Stat.GetData().QSkillCoolTime은 CharacterDataSO 값이라 의도적 유지). 에디터 컴파일 + 플레이 실측 필요. 특히 Q 이펙트는 Q_Skill 애니 클립에 AbilityBeat 이벤트를 꽂아야 나온다(쿨·궁게이지·글로우는 이벤트 없이 동작). 인스펙터 _abilities Q_Skill 슬롯 할당 확인.
남은 것 (선택) E 발동을 AbilityBeat로 — 지금 E는 즉발. 투사체 E가 생기면 SlotForState에 E_Skill→E_Skill + 비트 승격(= Phase 2). · CDR(쿨감) — _cd가 이미 dur를 저장하므로 ctx.CoolDown = base × CDR만 곱하면 됨(Phase 4).
